# Mosaic Pro の国別価格（買い切り1本）

価格の実体は [`pricing.csv`](pricing.csv)（Play へ流し込む唯一の情報源）。このファイルはその**根拠**と反映のしかた。
反映は `node scripts/push-play-pricing.mjs`（既定はドライラン。`--commit` で反映）。

> **【推定】の扱い**: 為替は 2026-09 時点の概算（1 USD ≈ ¥150 / €0.87 / £0.76 / ₩1,380 / R$5.4 / MX$18.5 /
> CLP 940 / COP 4,000 / PEN 3.6 / A$1.52 / C$1.37 / NZ$1.67 / CHF 0.81）で、**この環境から Play のストアページも
> Play Console も開けていない**。競合の価格は `docs/research/competitors.md` の検索結果の抜粋。
> **商品を作ったら Play Console の自動換算の値と見比べ、ずれが大きい国はここを直してから反映すること。**

## 先に: 商品と前提

- 商品: **一回限りの商品（One-time product）**、商品 ID **`mosaic_pro`**（RevenueCat に登録し、entitlement `pro` に紐付ける。
  `mobile/README.md` の「RevenueCat の設定」）。**RevenueCat のダッシュボードで非消費型（Non-consumable）に設定しないと、RevenueCat が購入を consume して買い切りでなくなる**（`submission-checklist.md` 5節）。
- **サブスクリプションは作らない**（`mobile/lib/purchase-offering.ts` がサブスクを売らないよう弾いている）。
- **Play Console の価格 CSV インポートと価格テンプレートは 2025 年に廃止された**。まとめて入れる手段は
  Play Developer API（`monetization.onetimeproducts`）だけで、`scripts/push-play-pricing.mjs` はそれを使う。
  手で入れるなら商品ページで国ごとに入力する。
- **CSV に無い国は Play の自動換算のまま**（US$5.99 を基準に、Play が現地の税と端数の慣例を付けて換算する）。
  CSV で上書きするのは (1) 心理的な価格を置きたい主要市場、(2) 為替と購買力がずれる中南米、の2種類だけ。
- **税**: 日本・EU・英国・韓国・豪州・ブラジルなどは**税込み**の表示価格を保存する。米国・カナダは税抜き（購入時に加算）。
  手取りの比較は「表示価格 ÷ (1 + 税率)」で行う（下表の「手取り US$」）。
- 個人の開発者アカウントで有料の商品を売るには、**お支払いプロファイル（販売者アカウント）と税務情報**の登録が先に要る。

## 基準: 日本 ¥980 / 米国 US$5.99

- **日本 ¥980**: `competitors.md` 5.3 節の提案（¥610〜¥980 帯）の上端。根拠は
  (1) クラス編成は年に1〜2回、何時間〜何日もかかる仕事が数分になる、
  (2) 個人向けの席替え・班分けアプリ（¥190〜¥300、$0.99〜$4.99）より上にしてよいが、学校向けの海外 SaaS
  （Class Maker 年$199〜・Class Creator 年$400〜・Class Composer 年$699〜）より2桁安い、
  (3) 教員が**自腹で、経費精算せずに払える**額に収める。¥980 は税込みで手取り ¥891 ≈ US$5.94。
- **米国 US$5.99**: `overseas-demand.md` O 節（en）の推定 US$4.99〜6.99 の中央。米国の教員は年 US$895 規模を自腹で教材に使う（同節）。
  ¥980 とほぼ等価（手取りで $5.94 対 $5.99）なので、日米で「どちらかが割安」にならない。
- **$4.99 にしない理由**: 個人の席替えアプリの上限（瞬速！席替え抽選 $4.99）と同じ枠に見え、
  「年に一度の学年全体の編成」を「席替えアプリ」と同じ値段で読まれる。一方で $6.99 以上は、レビュー0件の新規アプリでは分が悪い。
- **サブスクにしない理由**: 年に1〜2回しか使わない道具に月額は割に合わない（`competitors.md` 5.3 節）。掲載文にも「買い切り」と書く。

### 中南米の考え方

- **為替そのままでは高すぎる**（US$5.99 は ブラジルで約 R$32、チリで約 CLP 5,600）。`overseas-demand.md` A.8 の
  「現地のユーティリティ系アプリの相場と購買力」からの推定帯に置き、**対 US 0.43〜0.61** に収めた。
- ブラジル・チリは帯の**上端**、コロンビア・ペルーは**下端〜中ほど**。前者は私立の比率が高く（チリの私立補助校 53.9%）、
  買うのが学校の事務（年1回）という位置づけが当てはまりやすい。後者は WTP 低と見ている（A.4・A.5）。
- 無料で画面上の全機能（読み込み・編集・編成・手直し）が使えるので、Pro は「Excel・印刷が要る人が1回買う」もの。
  中南米で高めにしても、無料版の体験は損なわない。
- ウルグアイ・パラグアイ・ボリビア・中米は自動換算に任せた（市場が小さく、為替が比較的安定）。売れ始めたら行を足す。

### 韓国を ₩6,900 にしなかった理由

`docs/store-listing.md` の当初の目安は ₩6,900（¥980 の単純換算）だった。韓国は (1) 毎年・全学年で 반편성 があり、
(2) 分離配置が法的に必要な場面がある（学校暴力予防法）、(3) 韓国語の 반편성 専用ツールが見つからない（C 節）ので、
価格で割り引く理由が薄い。手取りで US と揃う ₩7,900 にし、₩6,900 はローンチ後の価格テストの候補にした。

## 運用

- **価格テスト**（Play Console の価格の実験）を最初に試す組み合わせ: 日本 **¥980 対 ¥730**、米国 **$5.99 対 $4.99**、
  ブラジル **R$19,90 対 R$14,90**、韓国 **₩7,900 対 ₩6,900**。繁忙期（日韓 2〜3月、南米 12〜2月、米 3〜5月、独 5〜7月）に回す。
- **アルゼンチン・トルコのような高インフレ国は四半期ごとに見直す**（固定した現地価格はすぐ陳腐化する）。
- **ロシアは行を作らない**（Play の有料取引が停止中）。
- Play の手数料: 年間 US$100 万までは 15%。この価格を見直す理由にはならない。
- 価格を変えたら `pricing.csv` を直してコミット → `node scripts/push-play-pricing.mjs`（ドライランで差分を目視）→ `--commit`。
  **Play Console で手で変えたら、必ず CSV にも書き戻す**（CSV が唯一の情報源）。

## 反映のしかた

```sh
# 1. 中身の確認（通信しない・鍵は要らない）
node scripts/push-play-pricing.mjs
# 2. 商品が見えるか（読むだけ）
node scripts/push-play-pricing.mjs --list --key play-service-account.json
# 3. 商品の今の設定と突き合わせる（読むだけ。価格を差し替える国・まだ設定の無い国を一覧する）
node scripts/push-play-pricing.mjs --plan --key play-service-account.json
# 4. 反映（既に設定がある国の価格だけ。販売の可否は今のまま。送った国を読み戻して一致を確かめる）
node scripts/push-play-pricing.mjs --commit --key play-service-account.json
# 商品にまだ設定の無い国も販売を始めるとき
node scripts/push-play-pricing.mjs --commit --enable-new-regions --key play-service-account.json
# status=confirm の行（BG・AR）も送るとき
node scripts/push-play-pricing.mjs --commit --include-unconfirmed --key play-service-account.json
```

- 鍵（サービスアカウントの JSON）は Google Cloud で作り、Play Console の「ユーザーと権限」で招待して
  「財務データの表示」「注文と定期購入の管理」を与える。**ファイルはコミットしない**（`.gitignore` の `*service-account*.json`）。
- スクリプトは**商品を作らない**。Play Console で `mosaic_pro` と購入オプションを先に作る（そのとき基準価格 US$5.99 を入れる）。
- **販売の可否（availability）は国ごとに今の値を保つ**（Play Console で販売を止めた国を、価格の更新で勝手に再開しない）。
  商品にまだ設定の無い国は `--enable-new-regions` を付けたときだけ AVAILABLE で足す。
- `--key` / `--package` / `--sku` に値が無い（`--key --commit` のような打ち間違い）ときは、既定値に落とさず止める。
- **このスクリプトは実際の API に対して一度も実行していない**（鍵が無いため）。初回は `--list`・`--plan` で読めることを確かめてから
  `--commit` すること。REST のパスは androidpublisher v3 の discovery 文書で確かめた（get / list は `oneTimeProducts`、
  patch だけ `onetimeproducts`）。
