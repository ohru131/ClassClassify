# コンテンツのレーティング（IARC）とターゲット層

Play Console →「アプリのコンテンツ」で回答する、レーティング質問票・ターゲット層とコンテンツ・関連する申告の値と根拠。
**広告の申告（広告なし）を先に済ませてからレーティングの質問票に進む**（順序が逆だと質問票に進めないことがある）。

> 質問の文言・並びは Play Console の改訂で変わる。ここに書いたのは 2026-10 時点の調査に基づく想定で、
> 実際の画面の質問に合わせて読み替えること。**迷ったら「実際にアプリでできること」に合わせて正直に答える**。

## 1. コンテンツのレーティング質問票

| 項目 | 回答 | 根拠 |
|---|---|---|
| メールアドレス（IARC からの通知先） | 開発者の連絡先メール | — |
| カテゴリ | **「ユーティリティ、仕事効率化、コミュニケーション、その他」** | 名簿を読み込んでクラス分けを計算する道具で、学習コンテンツを配信するアプリではない（「参考資料・ニュース・教育」は読み物・学習コンテンツ向け）。どちらを選んでも以下の回答は同じ |
| 暴力・流血 | いいえ | 該当する表現が無い |
| 性的な内容・ヌード | いいえ | 同上 |
| 不適切な言葉（卑語・差別的表現） | いいえ | アプリの文言とサンプル名簿（`public/samples/`）に含まれない。利用者が自分で入力する名簿の文字はアプリが配信するものではない |
| 規制物質（薬物・アルコール・タバコ） | いいえ | 該当なし |
| ギャンブル・模擬ギャンブル | いいえ | 該当なし |
| ユーザー同士のやり取り（チャット・投稿・ユーザー生成コンテンツの共有） | **いいえ** | アプリ内に他の利用者とつながる機能が無い。Excel・PDF の書き出しは OS の共有シートで利用者が自分の送り先へ渡すだけ（`mobile/lib/xlsx-files.ts`・`mobile/lib/print.ts`） |
| 位置情報の共有 | いいえ | 位置情報の権限を宣言していない（`mobile/app.config.ts` の `permissions: []`） |
| デジタル商品の購入 | **はい**（アプリ内購入：FairClass Pro の買い切り） | `mobile/lib/revenuecat-provider.tsx` |
| 制限の無いインターネットアクセス（ブラウザ等） | いいえ | アプリ内ブラウザ・WebView でのサイト閲覧は無い |
| 個人情報の要求 | いいえ | 名前・メール等を尋ねない。生徒の名簿は端末内にだけ保存（`data-safety.md`） |

**想定されるレーティング**: 全年齢（IARC 3+ / PEGI 3 / USK 0 / ESRB Everyone / ClassInd L / GRAC 전체이용가）＋「アプリ内購入あり」の表示。
**アプリの内容（文言・サンプル・機能）を変える更新のたびに、質問票の回答が今も正しいかを見直す。**

## 2. ターゲット層とコンテンツ

| 項目 | 回答 |
|---|---|
| ターゲットの年齢層 | **13～15 歳・16～17 歳・18 歳以上**（13 歳未満は含めない。2026-10-02 に Play Console へ保存） |
| ストアの掲載情報が意図せず子どもの興味を引く可能性 | **いいえ** |
| 子ども向けの「Teacher Approved（先生のおすすめ）」プログラム | **対象外**（13 歳未満を含まないため申し込めない） |

### 13 歳以上にする理由

- 主な利用者は教員・学校の事務担当だが、**高校生（生徒会・クラスの班分けなど）も使えるようにする**ため 13 歳以上にした。
- 13 歳未満を含めると **ファミリー ポリシー**の対象になる（使ってよい SDK・データの扱い・審査の追加項目）。13 歳以上なら対象外で、
  追加の質問も出なかった。生徒本人が使うのは任意で、アプリは名簿を端末の外へ出さない。

### 掲載情報で気をつけること（子ども向けに見えないように）

- スクリーンショット・フィーチャーグラフィックはアプリの実画面と、名簿・クラスの抽象的な図だけにする
  （キャラクター・絵本調のイラスト・子ども向けの言い回しを使わない）。今の素材（`submission-assets/`）はこの条件を満たす。
- 説明文の主語は「先生」「学年主任」「学校」。「子どもが楽しく使える」のような書き方をしない（`docs/store-listing.md`）。

## 3. その他のアプリのコンテンツの申告

| 申告 | 回答 | 根拠 |
|---|---|---|
| 広告 | **いいえ、広告は含まれていません** | 広告 SDK を入れていない（`mobile/package.json`）、`src/i18n/privacy.ts` |
| アプリへのアクセス | **すべての機能を、特別なアクセス権なしで利用できる**（ログイン無し）。Pro 機能は購入で開く（`reviewer-instructions.md`） | アカウント・ログインが無い |
| ニュースアプリ | いいえ | — |
| COVID-19 接触確認・健康状態 | いいえ（該当しない） | — |
| 政府機関のアプリ | いいえ | 個人の開発者が作るアプリで、政府・自治体の委託ではない |
| 金融取引の機能 | **該当なし**（「アプリに金融関連の機能は含まれていません」） | 買い切りの購入は Google Play の決済で、アプリ自体は金融サービスを提供しない |
| 健康アプリ | **該当なし** | 名簿の「支援の必要」の列は利用者が任意に作る項目で、健康の測定・管理を行うアプリではない |
| 広告 ID | 使用しない | `data-safety.md` |
| データセーフティ | `data-safety.md` | — |
