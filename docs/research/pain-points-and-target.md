## 0. 要約（10行）

1. クラス替えは**2〜3月**に、その学年の担任団（学年主任を中心に）が決める。基準は「学力・運動能力・人間関係（リーダー性）」＋配慮事項 [1][2][3]。
2. 配慮事項は多層: トラブル・いじめ関係の分離、欠席がちな子を仲の良い子と同じ組に、リーダー候補の分散、**ピアノ伴奏者を各組1人以上**、保護者同士・保護者と担任の相性まで [3][5][17]。
3. 道具は今も**紙カード・付箋・Excel手作業**が主流（日米豪とも）。海外事例では4日間＋追加会議、自動化で「教員1人あたり10時間・全校800時間削減」 [4][18]。
4. 手作業の本当の痛みは時間より「**主観が入る・公平性を説明できない・見落とし**」。国内でもExcelVBA自作や大学の研究例がある [6][7][19]。
5. 通常学級で支援が必要な可能性のある児童は**8.8%（小1は12%）**に増えており、配慮条件は年々増える方向 [20]。
6. 名簿は「校務系」情報で、**クラウド保存禁止**（文科省ガイドライン）・校外持ち出しの紛失は懲戒対象・私物スマホの教室持ち込み禁止の自治体もある [9][10][11][12]。→「端末内で完結」は最大の差別化であり、同時に私物スマホ前提のアプリは使い所が限られる。
7. 児童生徒端末は **ChromeOS 60% / iPadOS 31% / Windows 10%**（GIGA第2期）。教員側は校務系・学習系の統合・端末一台化へ移行中 [8][21]。
8. 公費でアプリ内課金を買うのはほぼ不可能【推定】。一方で教員の**4人に3人が年間に自腹経験あり**で、少額の自費買い切りは現実的 [22]。海外SaaSは学校契約で $1.60/生徒/年 [13]。
9. プライマリは**公立小学校の学年主任・担任（2学級以上の学年）**、セカンダリは**中学校の学年団**と、**班分け・席替え・宿泊行事の部屋割り**（年4〜6回、教員の過半数がストレスと回答）[23]。
10. 足りない機能の上位: 前年度クラスの分散（旧クラス均等化）、担任との相性・担任固定、結果の説明（なぜこの配置か）、印刷用の一覧・カード出力、班分けモード、匿名化（名前なしで番号だけで編成）。

## 1. 実際の困りごと

### 1.1 時期・関与者・進め方

| 項目 | 内容 | 出典 |
|---|---|---|
| 時期 | 2〜3月。学年末の成績をつける時期に並行して検討 | [1][2] |
| 決める人 | その学年の担任・教科で関わった教員がほとんど。1年間見てきた担任が特性と人間関係を把握しているため | [2] |
| 最終決定 | 学年案 → 管理職の確認 【推定：国内】。豪州の学校方針では「最終決定は担任と校長」と明文化 | [17] |
| 担任発表 | 担任・クラスは発表直前（4月1日の職員会議など）まで秘匿 | [24][25] |
| 小1の特殊性 | 幼稚園・保育園の先生から情報を聞き取って編成（幼保小連携）。川崎市のように**約1か月の仮クラス（プレクラス）**を経て5月1日に正式編成する例もある | [3][26] |
| 特別支援 | 担任・特別支援コーディネーター・個別対応教員が保護者と合意形成。進学時は移行支援会議で個別の教育支援計画を引き継ぐ | [27] |

**代表的な手順（国内の元教員・現役教員の解説より）**: 学年全員を成績順に並べ、各旧クラスの上位者をずらしながら新クラスに割り振り、平均点をそろえる。その後、リーダー性・足の速さ・ピアノなどで入れ替えて調整する [1][25]。

**作業時間**: 国内で「何時間かかるか」を示す一次資料は今回見つけられなかった（**未確認**）。海外事例では「名前を印刷して切り抜き、4日間にわたって作業、別途計画会議」「自動化で教員1人あたり10時間、全教員で800時間以上削減」 [4][18]。
【推定】国内の学年会でも、原案作成に担任が各自数時間、学年会で2〜4回程度の調整が一般的と思われる。定量データは教員アンケートで取る価値がある。

**背景の多忙さ**: 小学校教諭の平日の在校等時間は1日10時間45分（令和4年度調査）[16]。2〜3月は通知表・指導要録・次年度準備と重なる。

### 1.2 配慮事項の種類

| 種類 | 具体例 | 出典 |
|---|---|---|
| 学力 | 平均点・成績分布を均等化 | [1][2] |
| 運動能力 | 運動会・リレーの戦力を均等化（足の速さ） | [1][25] |
| リーダー性・積極性 | 学級委員候補を分散 | [3][25] |
| 人間関係（分離） | トラブル・いじめのあった子を離す | [3] |
| 人間関係（同じ組） | 欠席がちな子を仲の良い子と一緒に。海外では「友だち4人を書かせ最低1人と同じ組」方式 | [3][17] |
| 行事の役割 | **合唱の伴奏のためピアノを弾ける子を各組1人以上** | [5] |
| 支援の必要性 | 発達障害の可能性がある児童生徒 8.8%（小1 12%）。支援員の配置や担任との相性 | [20][27] |
| 保護者 | 保護者からの要望は増加傾向。保護者同士・保護者と担任の相性も考慮 | [2][28] |
| 部活・習い事 | 部活動の偏りを調整（中学） | [28] |
| 早生まれ・月齢 | 小1で月齢差が大きい | [26] |
| 行動面 | 海外では学力・社会性・行動の3軸で均衡 | [17] |

**Mosaic との対応**: 「学力（数値の平均均等化）」「運動能力・ピアノ・リーダー（該当者数の均等化）」「支援（段階の人数均等化）」「分離・同じ組（ペア制約）」は既存機能でそのまま表現できる。**表現しにくいもの**は、(a) 前年度クラスの分散（旧クラスごとの人数を均等化 ＝ 実は「値が数種類」の項目として入れれば可能だが、ひな形・説明に無い）、(b) 担任との相性（クラス番号と担任の対応が未定の段階で決めるため）、(c) 「友だちのうち最低1人と同じ組」（OR制約）、(d) 保護者要望の相反（A家は同じ組、B家は別の組を希望）[17]。

### 1.3 道具

- **紙カード・付箋**: 米国の小学校は今も付箋や青・ピンクの紙カード（性別の色分け）で配置を決めている [4]。国内でも名前カードを並べ替える方式が一般的と言われる 【推定：国内の一次記述は要確認】。
- **Excel**: 国内では表計算ソフトで手作業の並べ替えが一般的で、担当者の主観が入る点が課題と研究で指摘されている [7][19]。ExcelVBAによる自動編成システムを作った実践研究もある [6]。
- **校務支援システム**: EDUCOM「C4th」などの統合型校務支援システムは成績・出欠・学籍・年度更新を扱うが、**クラス編成（最適化）機能は検索範囲では確認できなかった**（要確認）[29]。
- **専用SaaS（海外）**: Class Creator（$1.60/生徒/年、豪AUD2.50）[13]、Class Composer（デジタルの生徒カード＋自動振り分け＋ドラッグで微調整。所要時間を最低50%削減）[18][30]、Class Solver [31]、Class Maker（友だち最低1人・能力・性別比。キャンプの部屋割りにも使える）[32]。**国内向けの市販専用ソフトは見当たらなかった**（競合の空白）。
- **席替え・班分けアプリ（国内）**: Let's席替え（無料＋課金）[14]、いちごプラス席替えするよ（最大14チーム）[15]、瞬速！席替え抽選 [33]、席替えメーカー（相性の悪い生徒を離す等の条件）[34]。ウェブルーレット（APUN）も班決め用途を訴求 [23]。

### 1.4 個人情報の扱い

- 文科省「教育情報セキュリティポリシーに関するガイドライン」（令和7年3月改訂）: **「校務系」情報資産のクラウドサービスへの保存は禁止**、校務外部接続系・学習系は内容に応じて判断 [9][10]。クラス編成に使う名簿（成績・支援情報・人間関係）は校務系に当たると考えるのが自然【推定】。
- 成績等の個人情報を記録媒体で校外に持ち出し紛失・盗難に遭えば**懲戒の対象になり得る**（山形県教委の基本ルール）[12]。
- 札幌市教委は盗撮事件を受け、**私用スマホ等の教室への持ち込みを原則禁止**（市立314施設）[11]。
- 一方で国は「次世代の校務DX」として校務系・学習系ネットワークの統合、ゼロトラスト、ロケーションフリー、教職員端末の一台化、校務支援システムのクラウド化を進めている [21][35]。→ 数年以内に「教員の1台の端末（Chromebook/iPad/Windows）で校務もする」形が増える【推定】。

**示唆**: 「名簿データはサーバーへ送らない・端末内で処理」は、教員がこのツールを使ってよいかを管理職・情報担当に説明するときの**最重要の根拠**になる。ただし (1) 私物スマホで成績・支援情報を扱うこと自体が規程違反になり得る、(2) Google スプレッドシート連携はクラウド保存に当たる、ので、アプリの訴求は「公用端末（校務PC・配布iPad/Chromebook）で使える」「オフラインで動く」を前面に、私物スマホは「名前を出さない番号だけのデータ」での利用を勧める設計が安全。

### 1.5 失敗したときの影響

- 偏ったクラスは1年間固定され、学級経営の難易度・学級崩壊リスク・保護者の不信に直結する【推定】。
- 保護者から「なぜうちの子がこの組か」と問われたとき、手作業だと根拠を説明しにくい（主観の問題）[7][19]。
- 相反する要望（A家は同じ組、B家は別の組）は実際に起き、最終判断は学校側 [17]。
- 見落とし（分離すべき2人を同じ組に）はいじめ・トラブルの再燃に繋がる【推定】。→ 制約違反0を機械的に保証できることは強い価値。

### 2.1 端末環境

- 児童生徒用（GIGA第2期）: **ChromeOS 60%・iPadOS 31%・Windows 10%**、平均単価5.5万円（MM総研、全国1741教委、2025年6〜7月調査）[8]。
- 教員の校務用は従来Windowsの校務PCが中心で、次世代校務DXで**一台化・クラウド化**が進行中 [21][35]。
- 私物スマホは自治体により教室持ち込み禁止 [11]。【推定】クラス編成のような成績・支援情報を扱う作業は、私物スマホよりも**校務PCまたは公用タブレット**で行う前提で設計すべき。
- Expoアプリで **Chromebook（Android アプリ／Webアプリ）と iPad** を両方押さえる意味は大きい。Chromebook では Play ストアが管理者に制限されている場合が多い【推定】ので、**Web版（PWA）を無料で残す方針は Chromebook 利用者の受け皿として重要**。

## 3. 購入・導入の障壁と価格設計への示唆

### 3.1 障壁

1. **公費でのアプリ内課金はほぼ不可能【推定】**。公立学校の購入は見積・発注・請求書払いが基本で、App Store/Google Play のクレジット決済と相性が悪い。Apple には学校向けに Apple School Manager（App とブック）で一括購入・配布する仕組みがある [39]が、配布は教委・情報担当の管理下になる。
2. **教委の承認**: 学校端末へのアプリ導入は、管理者（MDM）の許可アプリのみという運用が多い【推定】。
3. **個人情報**: 前述のとおりクラウド保存禁止・持ち出し制限 [9][12]。
4. **利用頻度が年1回**: 毎年2〜3月に1回しか使わない機能に継続課金は合わない【推定】。海外SaaSは年額の学校契約で成立しているが [13]、国内の個人教員には重い。
5. **自腹文化**: 公立小中の教職員の**4人に3人が2022年度に自腹の経験あり**（1,034人調査）[22]。少額なら自費で買う素地はあるが、「自腹を前提にした商品」への反感も同時にある【推定】。

### 3.2 価格・課金設計への示唆

- **個人向け: 自費の買い切り（数百〜千円台）**が現実的。「年1回のクラス替えのために毎月払う」は成立しにくい【推定】。現行方針（無料＋広告、Pro買い切りで広告除去＋xlsx出力）は方向として合っている。
- **Proの中身を「年1回の本番」に寄せる**: クラス替えは年1回だが、その1回の失敗コストが高い。xlsx出力に加えて「印刷用の一覧・カード」「条件の保存と翌年の再利用」「結果の根拠レポート」が Pro の価値になりやすい【推定】。
- **班分け・席替えを無料の常用機能にする**: 年4〜6回の接点で広告露出とアプリの定着を作り、2〜3月の本番で Pro に上げる導線【推定】。
- **学校・教委ライセンスは中長期**: 請求書払い・見積書対応が要る。Web版の無料維持と、将来の「学校単位での一括導入（Apple School Manager 経由の配布、見積書発行）」を分けて考える。
- **広告の配慮**: 学校端末・児童の前で表示される可能性がある。教員向けでも**子ども向け広告ポリシー（ファミリー向け・パーソナライズ無効）**を検討【推定】。授業中に不適切広告が映ると導入が止まる。

## 4. 結論

### 4.1 ターゲット

- **プライマリ: 公立小学校の学年主任（および2学級以上の学年の担任）**。配慮事項が最多で、毎年必ず発生し、学年主任が実務の決定者。Web版（校務PC）で本番のクラス替え、アプリ版（配布iPad/Chromebook）で確認・手直し。
- **セカンダリA: 公立中学校の学年団**（学級数が多く、部活・学力の均等化が重い）。
- **セカンダリB: 学級担任の班分け・席替え・宿泊行事の部屋割り**（頻度が高く、アプリ版と広告モデルに合う）。
- **周辺: 企業・自治体研修のグループ分け、塾・部活**（Web版で拾い、支払い意思が高い）。

### 4.2 ペルソナ

**ペルソナ1: 佐藤先生（42歳・公立小学校 4年学年主任・3学級）**
- 2月の学年会で5年生のクラス案を作る担当。105人分の名前カードを印刷して切り抜き、放課後に3人の担任と2〜3回並べ替える。
- 分けたい条件: 旧クラスの分散、学力、リレーの選手、ピアノ伴奏、支援が必要な児童と支援員の配置、トラブルのあった2組の分離、保護者から要望のあった3件。
- 痛み: 最後の入れ替えで「離すはずの2人」が同じ組に入っていないか何度も見直す。管理職に「偏りがない」ことを説明する資料が無い。
- 端末: 校務PC（Windows）、配布された iPad。私物スマホで名簿は扱わない。
- 刺さる言葉: 「条件違反0を保証」「名簿は端末の外に出ない」「偏りを表で説明できる」。

**ペルソナ2: 田中先生（29歳・公立中学校 2年担任）**
- 修学旅行の班・部屋割り、学期ごとの席替え・班替えを担当。年に5回以上グループを作る。
- 痛み: 1回あたりは30分程度だが、人間関係の見落としが後でトラブルになるのが怖い [23]。

- 支払い意思: 広告が邪魔なら数百円は自費で払う。
- 刺さる言葉: 「条件を入れて3秒で班が決まる」「前回と同じメンバーを避ける」。

## 5. 未確認事項（追加調査の候補）

- 国内のクラス替えに**実際に何時間・何回の会議**をかけているか（一次データ無し）。教員向けアンケート（X・note・教員SNS）で取れば掲載文の根拠になる。
- 全国の学校数と「1学年2学級以上」の学年の割合（学校基本調査の全国表で要確認）。単学級ではクラス替えが発生しない。
- 校務支援システム各社（C4th、スズキ校務、BLEND等）にクラス編成機能があるか。
- 教委がアプリ（学校端末へのストアアプリ導入）を許可する手続きの実例。
- 教員の私物端末での校務（名簿を扱う作業）に関する各自治体の規程の実例（札幌以外）。
